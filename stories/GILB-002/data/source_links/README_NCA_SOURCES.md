# GILB-002 — Official NCA source links

The following links point to official National Communications Authority source files. The data in `data/clean/` was transcribed from these official published monthly tables and reconciled to monthly totals. **The PDF files themselves are not currently included in this package; links are not an archived copy.** Download them and compare all transcribed counts before publication.

- January–December 2024: https://nca.org.gh/wp-content/uploads/2025/06/Market-Data-2024.pdf
- January–December 2025: https://nca.org.gh/wp-content/uploads/2026/02/Data-Subscription-December-2025.pdf
- December 2025–July 2026: https://nca.org.gh/wp-content/uploads/2026/10/Monthly-Industry-Data_July_2026-.pdf
- Data index: https://nca.org.gh/mobile-data/
- Statistical dashboard: https://statisticaldashboard.nca.org.gh/

**As of 2026-11-08** the public NCA monthly mobile-data downloads page lists Jan–Jul 2026 as the latest monthly data. This is subject to future updates. Do not mix NCA's mobile-voice, mobile-data traffic, fixed-data or mobile-money statistics into these MNO data subscription figures.

## Data integrity

- 31 monthly observations, 3 operators, 93 counts, source URL per row.
- All monthly totals reconcile as MTN + Telecel + AT.
- NCA report values were spot-checked at selected dates and notable monthly changes.
- Independent full row-by-row comparison to the downloaded PDFs remains an **open requirement**.
- No analyses, editorial claims, or publications have been automatically approved.

The source-table transcription snapshot is held under `../raw/`; this is **not** a downloaded copy of the NCA PDFs. The `data/clean/` file contains the standardised long-format dataset.
